# ux 피라미드
> 사용자에게 좋은 상호작용을 제공하기 위해 만족시켜야 하는 경험의 차원을 6개의 단계로 구분한 것


![Image](https://github.com/user-attachments/assets/e29c4536-889a-485a-8a70-aa925814fde9)

- 유용성
- 신뢰성
- 사용성
- 편의성
- 감성
- 의미성

피라미드는 위에서 아래로 내려갈수록 고려하기 쉬운 특성을 가진다.

## 유용성(useful)
- 서비스 내 사용자에게 필요한 정보 및 기능을 제공하는 것

예시 - 날씨 앱에서 현재 위치 기반으로 실시간 날씨와 시간대별 예보 제공, 쇼핑몰에서 상품의 재고 현황과 배송 예정일 실시간 표시

## 신뢰성(reliable)
- 사용자가 서비스를 이용하는 과정에서 안심하게 만드는 것

예시 - 맛집을 찾을 때 사용자 리뷰 및 평점 확인, 게임 내 해킹 방지를 위한 OTP 설정

## 사용성(usable)
- ‘쉽다’, ‘직관적이다’로 대표되는 특성

예시 - 은행 앱에서 자주 쓰는 이체 메뉴를 첫 화면에 배치, 온라인 쇼핑몰의 직관적인 카테고리 분류, 지도 앱에서 핀치 줌으로 지도 확대/축소

## 편의성(convenient)
- 사용자가 예상 했던 노력을 줄여주거나, 특정 맥락에서 ‘이런게 있었으면’ 하는 기대를 충족시켜주거나 원하는 정보 및 기능을 빠르게 이용하고 관리하게 해주는 특성

예시 - 영화 예매 시 최근 본 영화관을 첫 화면에 표시, 캘린더 앱에서 반복 일정 자동 생성

## 감성(pleasurable)
- 특별한 무언가를 제공하기보단 지금 있는 것을 더 매력적으로 만들어 사용자들이 재미를 느끼게 하도록 하는 특성

예시 - 좋아요 버튼 클릭 시 하트가 터지는 효과, 토스의 인터렉션 ui

## 의미성(meaningful)
- 마음을 움직이는 경험을 제시하는 특성

이처럼 ux의 구성요소는 맥락이라는 배경에서 동기 -> 행동 -> 고충 & 니즈 -> 태도로 이뤄진다.

즉, 특정 서비스를 사용할 때 특정 동기로 인해 무언가의 액션을 발생시키고, 그 액션에서 때론 고충을 때론 니즈를 필요로 하며 그 과정 속에서 서비스에 대한 한 유저의 태도가 결정되는 형태다.
